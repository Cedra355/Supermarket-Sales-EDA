# Superstore Sales Exploratory Data Analysis (EDA)

## Project Description

This project performs Exploratory Data Analysis (EDA) on a retail Superstore sales dataset to understand sales patterns, product performance, profitability, and customer trends.

## Dataset Information

- Dataset: "superstore dataset.csv"
- Source: "Kaggle – Superstore Dataset" https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed

1. Data loading and understanding
2. Data cleaning
3. Statistical analysis
4. Feature analysis
5. Correlation analysis
6. Data visualization
7. Business insights and recommendations

## Key Findings

The key findings will be documented using the actual results produced by the notebook, including sales patterns, product performance, profitability, and relationships between numerical variables where supported by the data.

## Business Recommendations

Recommendations will be based on the findings from the completed analysis, with a focus on improving sales performance and profitability.

## Repository Contents

- Jupyter Notebook — EDA code and outputs
- "superstore dataset.csv" — dataset
- PDF report — detailed project report
- Screenshots — code and output evidence
- Graphs — data visualizations

## How to Run the Notebook

1. Download the notebook and dataset from this repository.
2. Open "Google Colab" (https://colab.research.google.com/).
3. Upload the notebook.
4. Upload the CSV dataset to the Colab session.
5. Update the file path in the code if necessary.
6. Run the notebook cells from top to bottom.
